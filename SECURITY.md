# Security Policy

## Supported Versions

This is a self-hosted app with no separate release branches — only the latest commit on
`master` is supported. If you find a vulnerability, please check that it still reproduces
against the current `master` before reporting.

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/chaddy50/BooksNStuff/security/advisories/new)
feature (the "Report a vulnerability" button on the repo's Security tab) rather than opening
a public issue.

This is a solo-maintained project, so there's no fixed SLA, but reports will get a
best-effort acknowledgment and a fix will be prioritized based on severity.
